# **Complete UI Redesign Prompt — Flutter Mobile Application (iOS 26-Inspired Design Language)**

> **Role**
>
> Act as a Senior Flutter Developer, Senior Mobile UI/UX Designer, Motion Designer, and Product Designer with expertise in premium mobile experiences. Your objective is to completely redesign my existing Flutter (Dart) application by adopting a modern, spatial, and highly polished design language inspired by the latest generation of mobile operating systems. **Do not copy Apple's proprietary assets, icons, layouts, or branding.** Instead, recreate the design philosophy: layered depth, fluid motion, premium materials, and tactile interactions while preserving my application's functionality and navigation.

---

# Primary Goal

Redesign **only the user interface and user experience**.

Do **NOT** change:

- Business logic
- API integration
- Firebase implementation
- Database structure
- Models
- Navigation flow
- State management
- Backend functionality

The redesign must preserve all existing features while replacing the entire visual presentation with a more premium, immersive experience.

---

# Overall Visual Language

Create a true layered interface.

Each screen should consist of:

```
Background Layer

↓

Blur Material Layer

↓

Floating Content Cards

↓

Interactive Components

↓

Floating Navigation

↓

Bottom Sheets

↓

Dialogs

↓

System Overlays
```

Every layer should have a different elevation.

Nothing should appear glued to the background.

# Flutter Implementation

Use modern Flutter widgets and best practices.

Preferred approaches:

- Material 3 as a base, customized for a premium aesthetic
- `AnimatedContainer`
- `AnimatedScale`
- `AnimatedOpacity`
- `Hero`
- `TweenAnimationBuilder`
- `ImplicitlyAnimatedWidgets`
- `CustomPainter` only where necessary
- Smooth scrolling physics
- Reusable custom widgets
- Theme extensions for consistent styling
- Centralized design tokens (spacing, corner radius, elevations, animation durations)

Avoid hardcoded values where reusable theme definitions are appropriate.
